🏋️ Fitness Tracker — Kotlin Data Model Project
📖 Overview

This project is a console-based Kotlin application that models a Workout session for a Fitness Tracker app. It demonstrates key object-oriented programming concepts including:
Class design and blueprints
Primary constructors
init blocks for validation
Encapsulation of logic through member functions
Object creation and method invocation
The project focuses on clean data modeling and logical structuring before UI implementation.

🚀 Features
Create Workout objects with meaningful properties
Validate data using an init block
Calculate calories burned per minute
Mark workouts as completed
Display formatted workout summaries

🧠 Concepts Practiced
Kotlin Classes
Constructors
init Blocks
Member Functions
Encapsulation
Object Instances
Console Application Structure

📂 Technologies Used
Kotlin
Kotlin Playground / IntelliJ / Android Studio
